# Student Performance Prediction

## Project Overview
This project predicts students' final grades using Machine Learning based on their study time, absences, previous grades, and failures.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Dataset
Student Performance Dataset from the UCI Machine Learning Repository.

## Machine Learning Algorithm
Random Forest Regressor

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Model Training
6. Model Evaluation
7. Grade Prediction

## Features
- Analyzes student performance data
- Visualizes study time and grades
- Predicts final grades using Machine Learning
- Evaluates model performance using MAE and R2 Score

## Output
The model predicts the final grade of a student based on the given input features.

## Learning Outcomes
- Python programming
- Data analysis using Pandas
- Data visualization using Matplotlib
- Machine Learning using Scikit-learn
- Model training and evaluation
